DigiLIB

The digital librarian, packaged as an MCP server. Search papers and books across six free sources and export a cited literature review as LaTeX, all from the agent you already use. No API keys required.

Copy a line and paste it into your agent of choice. That's the whole setup.

Any other agent
Set up this MCP server for me: https://github.com/cars3/digilib-mcp (keyless, runs via uvx; setup guides are in the repo)

Works with Claude Code, Claude Desktop, Codex, Antigravity, Cursor, OpenCode, and any other MCP client. Per-agent setup guides live in the repository.

Agastya RAG

The Agastya RAG retrieval system, packaged as an MCP server. Point it at a folder of PDFs with embedded bookmarks and it builds a section index, so an agent can pull the passages that answer a question instead of carrying the whole document in context.

Setup is a local install: clone the repository, install into a venv, then register the agastya command with your client. Per-agent configs live in agent-instructions/agents.

Any other agent
Set up this MCP server for me: https://github.com/cars3/agastya (local venv install; register the agastya command with --mcp; setup guides are in agent-instructions/agents)

Works with Claude Code, Claude Desktop, Codex, Cursor, and any other MCP client. Needs Python 3.10 or newer; a CUDA GPU is recommended, though CPU inference works. The first query downloads the EmbeddingGemma model and may need Hugging Face access.

The MCP query ranks sections and chunks with dense embeddings; the hierarchy walk from the benchmark runs is not part of this server yet.
