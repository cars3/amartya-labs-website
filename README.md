# amartya-labs-website

Source for **andralabs.org** (Amartya Sai Andra's portfolio). Static HTML, no framework.
A tiny stdlib-only Python builder assembles the pages from modular source files, so every
edit happens in exactly one place.

## Structure

    build.py              Builder. `python3 build.py` writes docs/
    src/layout/base.html  Shared shell: <head>, nav, footer. Edit once, applies to all pages.
    src/data/             Structured content (JSON):
                            site.json        site-wide links (LinkedIn, X)
                            projects.json    project cards (Projects page + home selection)
                            experiments.json experiment cards + home preview rows
                            work.json        Work page rows (experience + leadership)
    src/pages/            One file per page = only that page's <main> content,
                          preceded by a front-matter comment:
                              <!--
                              title: Amartya Sai Andra · Projects
                              description: ...
                              active: projects        (nav key to mark current; omit on home)
                              scripts: globe.js       (optional; main.js is always added)
                              -->
                          Files: index.html, work.html, projects.html, experiments.html,
                          about.html, blog.html, mcp.html
    src/assets/           style.css, main.js, globe.js, favicon.svg (copied verbatim)
    docs/                 BUILD OUTPUT. Generated; never edit by hand. This folder is what
                          gets served (GitHub Pages / Railway / any static host).

## Common edits

- Add or change a project: `src/data/projects.json`. Set `"featured": true` plus a `"short"`
  description to also show it on the home page. `"links"` render as the small links in each
  card (`{"label": "watch", "href": "..."}`, or `{"kind": "meta", "label": "2023"}`).
- Add an experiment: `src/data/experiments.json`. Give it `row_year` / `row_text` / `row_tag`
  to also show it in the home page preview rows.
- Change a job or leadership item: `src/data/work.json`.
- Change navigation, footer, or <head>: `src/layout/base.html`.
- Change a page's copy or headings: the matching file in `src/pages/`.
- Colors, type, layout rules: `src/assets/style.css` (the palette is the `:root` block).

## Tokens (usable in pages and JSON values)

- `{{base}}`  relative site-root prefix, filled per page (`./` or `../`). ALL internal links
  and asset paths use it, so the same build works at any URL prefix (custom domain root,
  GitHub Pages project sites under /repo/, localhost).
- `{{LINKEDIN}}`, `{{X}}`  site links from site.json
- `{{projects_all}}`, `{{projects_featured}}`  rendered project card grids
- `{{experiments_all}}`, `{{experiments_rows}}`  rendered experiment cards / home rows
- `{{work_rows}}`, `{{leadership_rows}}`  rendered Work page rows

## Build & preview

    python3 build.py                 # build src/ -> docs/
    python3 build.py --serve 8080    # build, then preview at http://localhost:8080/
    # or: python3 -m http.server 8080 --directory docs

## Deploy

- GitHub Pages: serves the `main` branch, `/docs` folder.
- Railway (planned for andralabs.org): serve `docs/` as a static site.

## House style

- No em or en dashes anywhere in copy. Use commas, colons, or parentheses.
- Sentence case for headings, buttons, and links.
- Edit the modular sources only; `docs/` is regenerated by the builder.
